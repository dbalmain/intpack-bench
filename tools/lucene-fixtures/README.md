# Lucene 10.3.1 fixtures

`src/codec/lucene/lucene103-fixtures.tsv` holds byte-exact outputs of Lucene's
`ForUtil`, `ForDeltaUtil`, `PForUtil` and the docs-only postings stream of
`Lucene103PostingsWriter`, generated by `GenFixtures.java` against
`lucene-core-10.3.1.jar`. One case per line, tab separated:

```
for       <bpv>  <128 ints>   <hex bytes>
fordelta  <bpv>  <128 deltas> <hex bytes>    bpv = ForDeltaUtil.bitsRequired(deltas)
pfor      -      <128 ints>   <hex bytes>
docs      -      <doc ids>    <hex bytes>    the term's slice of the .doc file
```

Regenerate (the class lives in Lucene's package to reach package-private API):

```sh
curl -sLO https://repo1.maven.org/maven2/org/apache/lucene/lucene-core/10.3.1/lucene-core-10.3.1.jar
mkdir -p gen/org/apache/lucene/codecs/lucene103 && cp GenFixtures.java gen/org/apache/lucene/codecs/lucene103/
nix shell nixpkgs#jdk21 -c sh -c 'javac -cp lucene-core-10.3.1.jar -d out gen/org/apache/lucene/codecs/lucene103/GenFixtures.java && java -cp lucene-core-10.3.1.jar:out org.apache.lucene.codecs.lucene103.GenFixtures ../../src/codec/lucene/lucene103-fixtures.tsv idx'
```
